# 番茄阅读器-网页版

在电脑浏览器里看番茄小说：首页、搜索、目录、正文排版，还能同步手机上的书架和阅读进度。

不用装安卓模拟器，不用改手机 App，装好就能用，界面干净，没有广告和推荐干扰。

---

## 能做什么

- **首页**：推荐、巅峰榜、排行榜（男频/女频分类）、最近更新
- **找书**：站内搜索，或者从首页榜单直接点开
- **阅读**：目录分卷展示，正文按段落排版，可以调主题、字体、字号、行距、页宽，支持上下滚动和左右翻页
- **换主题**：浅色、护眼、绿色、蓝色、粉色随时切；还能切到 WPS 风格的「文档主题」或「VS Code 主题」，阅读页直接变成一份正在处理的文档或代码，摸鱼更安心
- **全屏阅读**：一键全屏，屏幕上只剩正文，按 Esc 退出
- **接着上次读**：自动记住读到哪一章，下次打开直接续上
- **翻页快**：接下来几章合并成一次请求提前取好，滚动模式自动接着往下排，点“下一章”基本不用等
- **账号（可选）**：扫码登录自己的番茄账号，同步书架和阅读进度
- **站点设置**：访问密码、两步验证、番茄账号存在哪里
- **设备池**：同时维护几台匿名设备，取正文命中 403 或风控空响应时自动换一台重试

## 怎么跑起来

### 方式一：Docker（推荐）

前提：电脑上已经装好 Docker（Docker Desktop 或 Docker 引擎）。

1. 把本项目下载或克隆到本地，进入项目文件夹
2. 执行：

   ```bash
   docker compose up -d --build
   ```

3. 浏览器打开 <http://localhost:8080>
4. 想停掉：`docker compose down`

### 方式二：直接运行（需要 Go 1.22 或更高）

```bash
go run ./cmd/server -addr :8080
```

然后打开 <http://localhost:8080>。

### 方式三：用启动脚本

```bash
./start.sh            # 编译并在后台启动，默认 8080
./start.sh --status   # 看有没有在运行
./start.sh --stop     # 停止
```

## 打开之后怎么用

1. 首页逛一逛，或者在顶部搜索框输入书名、作者
2. 点一本书 → 看目录 → 点章节开始读
3. 阅读页里的「阅读设置」可以调背景、字体、字号、行距和翻页方式
4. 想同步手机的书架和进度，点右上角「登录」，用番茄小说或抖音 App 扫码
5. 想改站点设置，点右上角的齿轮按钮

## 站点设置

首页右上角的齿轮按钮，打开的是**站点设置**，和阅读页里的排版设置是两回事。设置改完立刻生效，重启也不会丢。

### 访问密码

打开开关并填好账号密码，以后谁打开这个网址，都要先输入账号密码才能进首页、看内容。

- 密码至少 6 位，大小写、数字、符号都不限
- 登录一次可以保持 30 天
- 同一个网络连续输错 8 次，会锁 10 分钟

### 两步验证

先开启访问密码，才能开启两步验证。

1. 点「开始设置」，面板会给出一串密钥
2. 在手机上的验证器 App（Google Authenticator、微软 Authenticator 等）里选「手动输入密钥」，把密钥粘进去
3. 把 App 里显示的 6 位数字填回面板，点「确认开启」

之后每次登录，除了密码还要输一次 6 位验证码。想关掉时同样要输一次当前验证码。

### 番茄账号绑定

把你自己的番茄账号绑到这个网页上，用来同步书架和阅读进度。先选保存位置，再在下面登录。

| 选项 | 意思 |
| --- | --- |
| **仅当前浏览器保存** | 只存在你现在用的这个浏览器里。换一台电脑、换一个浏览器，或者别人打开这个网址，都是没登录的状态。 |
| **保存到 Docker 容器** | 存在服务端（Docker 数据卷里）。只要打开这个网址，用的都是这个番茄账号。**建议同时开启访问密码**，否则别人也能用你的账号。 |

两种方式都可以扫码登录，也可以粘贴 Cookie 登录。切换方式后，需要重新登录一次。

## 数据存在哪

- **Docker 运行**：登录凭据和站点设置都在数据卷 `account-session` 里（容器内路径 `/app/session`）。重建镜像、升级版本都不会丢。
  - 备份：`docker run --rm -v fanqieweb_account-session:/s -v "$PWD":/b alpine tar czf /b/backup.tgz -C /s .`
- **本地运行**：放在 `data/account.json`（番茄登录凭据）和 `data/settings.json`（站点设置）
- 这两个文件包含登录信息和密码摘要，不要发给别人，也不要提交到 Git

## 设备池

取正文本质上是拿一台匿名设备身份去换内容。单台设备被风控之后，所有 `/reading/*` 接口都会返回 HTTP 200 + 空响应体，没有错误码可判断，只能整台换掉。设备池就是为此准备的：

- 默认 3 个槽位。首槽启动时注册，其余槽延迟 10 秒 / 30 秒错峰注册，避免「短时间批量注册」本身触发风控
- 每个槽独立记连续失败，连续 2 次失败判为 dead，自动切到下一台健康设备并重新申请内容密钥
- 刚换过设备又失败时不再继续换：这时问题多半在出口网络或上游整体故障，继续换只是白注册
- dead 槽 24 小时内不补员；三个槽全 dead 时延迟 5 分钟整体重置，且 24 小时内最多自动重置一次

设备池放在 `data/device_pool.json`（Docker 下是数据卷里的 `/app/session/device_pool.json`），只保存设备 ID 与健康状态，不保存内容密钥。旧版的 `data/device.json` 会在启动时自动迁移成第一个槽位，不需要重新注册。

管理接口（排查用，平时不需要动）：

| 接口 | 作用 |
| --- | --- |
| `GET /api/device/pool` | 查看每个槽的设备、健康状态、失败次数 |
| `POST /api/device/pool/rotate` | 手动换设备；带 `{"index":N}` 可指定槽位 |
| `POST /api/device/pool/refill` | 给 dead 槽补一台新设备，`{"index":N}` |
| `POST /api/device/pool/reset` | 清空并重建整个池子 |

## 配置（一般不用改）

| 参数 | 环境变量 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `-addr` | `FQ_ADDR` | `:8080` | 监听地址，想换端口改这里 |
| `-font-map` | `FQ_FONT_MAP` | `data/font_map.json` | 字体映射表位置 |
| `-account-file` | `FQ_ACCOUNT_FILE` | `data/account.json` | 番茄登录凭据保存位置 |
| `-settings-file` | `FQ_SETTINGS_FILE` | `data/settings.json` | 站点设置保存位置 |
| `-prefetch-window` | `FQ_PREFETCH_WINDOW` | `0` | 后台预取前后几章，`0` 表示只取当前章 |
| `-prefetch-batch` | `FQ_PREFETCH_BATCH` | `3` | 单次批量请求最多取几章，翻页预取按这个合并 |
| `-prefetch-workers` | `FQ_PREFETCH_WORKERS` | `1` | 取章并发数 |
| `-prefetch-delay-ms` | `FQ_PREFETCH_DELAY_MS` | `1500` | 两次取章之间的最小间隔（毫秒），被限流时调大 |
| `-device-pool` | `FQ_DEVICE_POOL` | `data/device_pool.json` | 设备池保存位置；留空则退化为旧的单设备模式 |
| `-pool-size` | `FQ_POOL_SIZE` | `3` | 设备池槽位数（最多 10） |
| `-device-file` | `FQ_DEVICE_FILE` | `data/device.json` | 旧版单设备身份文件，仅在设备池为空时用于迁移 |

## 遇到问题

**章节加载失败，提示被限流**
翻得太快会触发风控。页面会显示还要等多久，倒计时结束自动重试。
经常遇到的话，把 `FQ_PREFETCH_DELAY_MS` 调大（比如 `3000`），或者把 `FQ_PREFETCH_BATCH` 调到 `2`。

**正文里出现方块或者奇怪的符号**
说明这本书用了新的混淆字体，当前的字体映射表没覆盖到。可以自己重新生成一份：

```bash
pip install fonttools pillow numpy brotli
python3 tools/build_font_map_img.py --obf obf.woff2 --ref SourceHanSansSC-Regular.otf --out data/font_map.json
```

生成后重启一下服务就生效（Docker：`docker compose restart`）。

**番茄账号突然变成未登录**
Cookie 会过期。重新登录一次即可。

**忘记访问密码了**
删掉配置文件就能恢复成不需要密码：
- Docker：`docker compose down`，再删掉数据卷 `account-session`，然后重新启动
- 本地运行：删掉 `data/settings.json` 后重启

注意：这样会同时清掉两步验证和站点设置，番茄账号的登录状态也会一起重置（如果用的是「保存到 Docker 容器」）。

**手机或别的电脑能访问吗**
可以。把地址换成运行这台电脑的局域网 IP，比如 `http://192.168.1.10:8080`，前提是防火墙放行 8080 端口。想从外网访问，请自己做反向代理并开启访问密码。
