生效日期：2026-11-21

一句话概括：这是一个只在你自己的机器上运行的阅读工具，不含任何作品内容，不收集统计、不做广告。 开始使用即表示你已读完并接受本说明；不接受请立即停止使用并删除本项目。

一、这是什么，适合谁用

本项目是一套可以自己部署的阅读工具，用来在电脑浏览器里浏览和阅读内容，并按小说的样子排版。

  • 适合：个人在自己的电脑或自己的服务器上自用。
  • 不适合：对外提供服务的站点、团队或公司内部系统、任何需要多人共用的经营场景。

二、允许的用法

  • 个人学习、技术研究、自用阅读
  • 在自己的设备上部署、修改、调试本项目
  • 在遵守本说明的前提下，分享本项目的源代码

  • 商业用途：包括但不限于出售、收费服务、付费墙内部署、与广告或引流结合
  • 对外提供服务：搭建供他人访问的公开站点、对外提供下载或接口、二次打包分发

  • 侵犯他人权利：复制、传播、改编受保护的作品，或规避合法的付费与授权机制

八、数据与隐私

会处理哪些信息

信息用途存放位置
站点访问账号名、密码摘要（PBKDF2-SHA256，不可还原为明文）验证是否允许访问本站服务端设置文件 / 数据卷
两步验证密钥（TOTP）登录时校验动态验证码服务端设置文件 / 数据卷
账号登录凭据（Cookie）及账号昵称、头像同步书架与阅读进度按设置存在你的浏览器，或服务端数据卷
阅读偏好（主题、字体、字号、行距、翻页方式）与上次阅读位置下次打开时保持排版和续读位置你的浏览器本地存储
请求日志（方法、路径、耗时）排查故障服务端运行日志

由谁来处理

  • 你自己部署：所有数据都在你的机器上，没有第三方运营方参与收集。
  • 你访问别人部署的站点：该站点的运营者可以接触到上表中的服务端数据，请直接向运营者了解其处理方式。

浏览器里会保存什么

  • fqweb_auth：站点登录状态，签名 Cookie，默认保留 30 天，退出登录即失效。
  • fq-fanqie-cookie：选择“仅当前浏览器保存”时，账号凭据存在这里，退出登录会删除。
  • fq-prefs-v2、fq-theme、fq-last-read-v1：排版偏好与上次读到哪一章。

这些内容都保存在你自己的浏览器里，清除浏览器站点数据即可全部删除。

不会做的事

  • 不使用第三方统计、埋点、广告或指纹识别脚本
  • 不建立用户画像，不出售、出租或共享上述信息
  • 不主动把你的阅读记录、书架或本地内容上传到本项目之外的服务器
  • 不在代码、日志或页面中输出你的密码、Cookie 原文

会发往第三方的请求

为了取回书籍与章节内容、完成账号登录，本服务会直接向内容提供方的官方服务发起请求，包括内容、搜索、登录（扫码）等接口。这些请求会携带随机生成的设备标识和你登录后的账号凭据，属于与内容提供方之间的正常通信，并受对方隐私政策与服务条款约束，本项目无法控制其数据处理方式。

站点本身不引入任何第三方 CDN、统计或广告域名。

日志

服务端只记录请求方法、路径和耗时，以及少量运行状态（例如登录成功时记录账号昵称、开启访问密码时记录账号名），用于排查问题。日志保存在运行本服务的机器上，不对外传输；清理时直接删除日志文件即可。

安全措施与其局限

  • 访问密码只保存加盐摘要；密钥与凭据文件权限为仅服务进程可读（0600）
  • 登录状态用服务端密钥签名的 Cookie 传递，Cookie 标记为 HttpOnly、SameSite=Lax
  • 同一来源连续多次密码错误会临时限制登录

需要你注意：如果站点通过公网访问却没有启用 HTTPS，密码和 Cookie 在网络中可被中间人读取。请自行配置 HTTPS 反向代理，并开启访问密码。

九、保存多久，怎么删除

除运行日志外，数据没有固定的自动过期时间，一直保存到你主动删除：

  • 退出账号：在首页或设置面板里点“退出登录”
  • 清除浏览器数据：浏览器设置中清除本站数据，会同时删除排版偏好与续读位置
  • 删除服务端数据：停止服务后删除设置文件与数据卷（Docker 下为 account-session）
  • 关闭访问密码或两步验证：在首页右上角设置面板中操作

删除后不可恢复。
